# ABS-185: how fast agent plugins read their agents' output

Agents are plugins now: an agent plugin's script, in a JavaScriptCore context
inside AbstractCore, turns each line its agent prints into `AgentEvent`s. Every
chat's log is folded again when it opens, on another Mac and in history search,
so this is measured against the Swift parsers the scripts replace, on today's
recorded fixtures (`Packages/AbstractCore/Tests/AbstractCoreTests/Fixtures`),
read many times over.

- **Replay**: lines handed to the script 512 at a time, as `ChatStream` replays a log.
- **Live**: one line at a time, as a running chat reads it.

Release build (Apple silicon, `-c release -Xswiftc -enable-testing`), per 100
lines, measured before the Swift parsers were deleted:

| Agent | Lines | Swift parser | Plugin, replay | Plugin, live |
|---|---|---|---|---|
| Claude Code (7 fixtures × 200) | 24,000 | 3.32 ms | 6.51 ms (1.96×) | 7.77 ms (2.34×) |
| Codex (3 fixtures × 200) | 4,000 | 1.62 ms | 2.88 ms (1.77×) | 3.95 ms (2.44×) |
| OpenCode (4 fixtures × 200) | 3,400 | 3.82 ms | 1.40 ms (0.37×) | 2.36 ms (0.62×) |
| Muse Code (10 fixtures × 200) | 60,400 | 11.25 ms | 2.10 ms (0.19×) | 3.44 ms (0.31×) |

All four are inside the design note's budget of 3× Swift. OpenCode's and Muse's
scripts are faster than the Swift they replace: `JSON.parse` is quicker than
decoding into `JSONValue`, and a batch crosses into the script once. Claude's
and Codex's are about twice as slow. To give exactly the events Swift gave, they
read JSON with a reader that copies Foundation's rules (a trailing comma
accepted, the first of a repeated key kept, a lone surrogate refused), where
`JSON.parse` would differ, and that reader is slower. A 6,000-line Claude chat
replays in about 0.4 s instead of 0.2 s. A later change can try `JSON.parse`
first and fall back to the strict reader only where the two can disagree.

Handing events back (JavaScript objects to `JSONValue` to `AgentEvent`) is
most of the rest of what a plugin line costs.

`AgentParseBenchmark` (`swift test --filter AgentParseBenchmark`) reports each
plugin's numbers and fails only when replay passes 100 ms per 100 lines, a
plugin gone badly wrong rather than a busy CI Mac. Each plugin's calls hold one
lock, so one plugin's chats parse a line at a time between them; another
plugin's never wait on it.
