# ABS-133: Organizations need a product decision

ABS-133 proposes an **Organization** above each project. People would create one, assign projects to it, move projects between organizations, and use organization-level account, budget, and screen filters. This is a new concept in Abstract's navigation and settings that users would have to learn.

ROADMAP.md says: “Correctness before orchestration. Make the concepts Abstract already has (Chats, Changes, Commit, Push, PR, Automations, Devices) behave correctly in more cases before adding new concepts or encoding one team's workflow.” Its ticket instructions also say to stop and open a draft PR when the work needs a new concept the user must learn.

The ticket was accepted in Todo, but the proposal conflicts with that product rule. No implementation is included. A person needs to decide whether Organizations should be an exception to the rule or whether the need can be addressed using existing concepts, then revise or reaffirm the ticket before implementation.
